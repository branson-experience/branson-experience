# AI Commit Below Steps 

repo: https://github.com/branson-experience/branson-experience.git

1) Create/Update Changelog.md with the latest changes.
   (The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
   and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html))

2) Add the date and list the latest changes at the top of Changelog.md.

3) Stage, commit, and push:
   git add . && git commit -m "See Changelog.md" && git push

## Dev Only
